# Liu Xingzhou · 个人学术主页

双击 `index.html` 可在浏览器中预览英文主页，从导航栏进入中文版。上传和分享时，请保留 `assets/` 文件夹。

## 发布到 GitHub Pages

1. 登录 `JasonDonaldLiu`，在 GitHub 创建名为 `jasondonaldliu.github.io` 的公开仓库，勾选 **Add README**。
2. 将本目录内的网页文件上传到仓库的 `main` 分支根目录。仓库首页应直接显示 `index.html`、`zh.html`、`style.css` 和 `assets/`。可用本文件替换 GitHub 自动生成的 `README.md`。
3. 在仓库的 **Settings → Pages** 中将 **Source** 设为 **Deploy from a branch**，选择 **main** 和 **/(root)**，点击 **Save**。
4. 部署完成后访问 [主页](https://jasondonaldliu.github.io/)。

## 修改内容

- `index.html` 是英文主页，`zh.html` 是中文主页，两页共用 `style.css`。
- `assets/usagi-avatar.jpg` 是头像，`assets/liu-xingzhou-cv.pdf` 是网站提供下载的英文简历。
